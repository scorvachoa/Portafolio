Contexto del proyecto

La producción constante de contenido para redes sociales y plataformas digitales requiere realizar tareas repetitivas como escribir copys, organizar material visual y publicar contenido.

Para optimizar estos procesos se desarrollaron herramientas en Python que permitieran automatizar parte del flujo de trabajo y mejorar la eficiencia en la gestión de contenido.

Ejemplo de lógica del script

					
import os, random, requests
from dotenv import load_dotenv
from google import genai

load_dotenv()
PAGE_ID = os.getenv("FB_PAGE_ID")
TOKEN = os.getenv("FB_PAGE_TOKEN")
GEMINI_KEY = os.getenv("GEMINI_API_KEY")

img = random.choice(os.listdir("images"))
img_path = f"images/{img}"

client = genai.Client(api_key=GEMINI_KEY)
copy = client.models.generate_content(
    model="gemini-2.5-flash",
    contents=f"Escribe un copy corto para Facebook sobre turismo en Perú."
).text

url = f"https://graph.facebook.com/v19.0/{PAGE_ID}/photos"
files = {"source": open(img_path,"rb")}
data = {"caption": copy, "access_token": TOKEN}

print(requests.post(url, data=data, files=files).json())
